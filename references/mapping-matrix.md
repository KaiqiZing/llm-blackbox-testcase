## 二、组合策略：四层叠加，不是多选一

同一个测试点通常需要 2~3 个方法分工协作：

| 层 | 职责 | 方法 | 说明 |
|---|------|------|------|
| 第一层 · 分域 | 把输入空间切成有效域/无效域 | 等价类划分 | 骨架。所有后续方法在这个骨架上加密 |
| 第二层 · 组合 | 处理多条件、多参数 | 判定表 / 因果图 / 正交 / Pairwise / 分类树 | 条件互斥强耦合用因果图；条件少而独立用判定表；组合爆炸用正交或配对降维 |
| 第三层 · 加密 | 在边界上取上点/离点/内点 | 边界值分析 | 缺陷 70% 以上藏在边界附近；模型最容易漏的一层 |
| 第四层 · 补漏 | 历史缺陷驱动的反向用例 | 错误推测法 / 探索性测试 | 幂等、并发、超时、重放、非法时序，前三层覆盖不到 |

**分工原则**：辅助方法不得与主方法覆盖同一批数据。判定表里的"价格合法"是布尔值，边界值问的是 10.20 与 10.21 的差别——分工写清楚，用例才不重复。

## 三、Few-Shot 示例（方法选择的判断范式）

> 这些是判断范式，不是穷举。生成时按范式推理，不要照抄示例中的业务数字。

### 示例 a：连续输入 / 单值边界 → 等价类划分 + 边界值分析

**输入**：年龄字段，规则"投保人年龄 18~65 周岁"。
**特征画像**：单输入；有效域 [18,65]；无效域 {<18, >65, 非整数, 空}；边界闭区间。
**方法选择**：等价类划分（主）—— 1 个有效类 + 4 个无效类；边界值分析（辅）—— 17/18/19、64/65/66。
**选择理由**：单输入独立决定结果、有明确上下界，命中 F1 连续数值区间。
**用例骨架**：17（下离点，拒）、18（下点，过）、30（内点，过）、65（上点，过）、66（上离点，拒）、17.5（非整数，拒）、空（拒）。
**同类迁移**：金额范围、委托价格区间、可购数量上限、转账限额。

### 示例 b：离散条件布尔组合 / 分支互斥 → 判定表法 + 因果图法

**输入**：风控规则"满足以下任一即拦截：黑名单命中；单日累计 > 50 万；新设备登录且异地"。
**特征画像**：条件 4 个（黑名单 / 超限额 / 新设备 / 异地），结果 2 个（拦截 / 放行）；条件"新设备且异地"内部是包含关系。
**方法选择**：判定表法（主）—— 覆盖 2^4=16 组合中所有合法组合；因果图法（辅）—— "新设备"与"异地"存在包含约束，先标注再化简。
**选择理由**：多条件布尔组合、结果唯一，命中 F5；条件间有包含约束，叠加 F6。
**用例骨架**：每组合一行，重点列"新设备=真 ∧ 异地=假"与"黑名单=真 且其他全假"这类边界组合。
**同类迁移**：计费折扣叠加（会员折扣与满减互斥→因果图标 E 约束）、权限矩阵、促销规则、核保规则。

### 示例 c：多参数 / 多配置组合爆炸 → 正交试验设计 + 成对测试（Pairwise）

**输入**：APP 兼容性验证，4 个参数：OS{iOS, Android, HarmonyOS} × 机型档位{旗舰, 中端, 入门} × 网络{WiFi, 5G, 4G, 弱网} × 系统语言{中文, 英文}。
**特征画像**：组合总数 3×3×4×2 = 72 > 20；参数间交互弱，两两交互为主。
**方法选择**：正交试验设计（主）—— L9(3^4) 覆盖主要效应；Pairwise（辅）—— 补齐全部两两参数对。
**选择理由**：组合规模 72 > 20 且交互弱，命中 F9 参数组合爆炸。
**用例骨架**：正交表 9~12 条 + Pairwise 补充至两两覆盖 100%；附损失说明（放弃三因子以上交互，风险：OS×网络×语言的组合异常需专项补测）。
**同类迁移**：多种筛选条件组合、委托类型×板块×时段、浏览器×分辨率矩阵、报表导出参数组合。

### 示例 d：状态机 / 生命周期 → 状态迁移测试 + 场景法

**输入**：订单状态：待支付 → 已支付 → 已发货 → 已签收 / 已取消 / 已退款。
**特征画像**：状态 6 个；事件 8 类；非法迁移存在（已签收→取消）。
**方法选择**：状态迁移测试（主）—— 状态-事件矩阵全覆盖 + 非法迁移用例 ≥ 3；场景法（辅）—— 把迁移放进业务上下文（大促、库存不足）。
**选择理由**：对象有生命周期、同操作不同状态结果不同，命中 F10。
**同类迁移**：证券委托单流转、审批流、账户状态、设备连接状态。

### 示例 e：端到端业务流程 → 场景法 + 错误推测法

**输入**：证券开户到首笔交收：开户 → 风险测评 → 银证转账 → 委托 → 成交 → 清算交收 → 对账。
**特征画像**：7 个环节跨 4 个系统；基本流 1 条、备选流 5 条、异常流 ≥ 6 条（测评不通过、转账失败、废单、清算延迟……）。
**方法选择**：场景法（主）—— 基本流/备选流/异常流场景清单；错误推测法（辅）—— 断链、重复对账、跨日切换盲区。
**选择理由**：跨模块端到端链路、存在多种走法与中断恢复，命中 F11/F18。
**同类迁移**：理赔流程、订单履约、审批到放款。

### 示例 f：金额 / 费率计算 → 边界值分析 + 等价类划分（数值计算型）

**输入**：佣金 = max(5 元, 成交额 × 费率)，费率按资产分三档。
**特征画像**：公式输出；分档临界点；最低收费兜底；金额精确到分。
**方法选择**：边界值分析（主）—— 成交额使"成交额×费率"恰好等于 5 元的分界点两侧；等价类划分（辅）—— 三档费率各取代表值。
**选择理由**：公式计算、有分档与舍入，命中 F13。
**关键用例**：分界点 ±0.01 元、成交额 0、超大成交额、费率档临界资产 ±1 元。
**同类迁移**：冻结金额、利息、税额、涨跌停价四舍五入。

### 示例 g：动态阈值 → 边界值分析（动态边界）+ 等价类划分

**输入**：连续竞价价格笼子：买入价 ≤ 买入基准价 × 102%（部分板块另有 +0.1 元孰高兜底）。
**特征画像**：阈值随行情浮动；基准价有四层回退（最低卖价→最高买价→最近成交价→前收）；板块规则有差异。
**方法选择**：边界值分析（主）—— 多组基准价 × 上点/离点；等价类划分（辅）—— 基准值行情态分层（有卖一/无卖一/无盘口/无成交）。
**选择理由**：阈值随基准值浮动，命中 F4。
**同类迁移**：动态保证金率、实时风控限额、动态定价。

### 示例 h：时序 / 并发 / 幂等 → 场景法 + 错误推测法

**输入**：同一账户在两台终端同时提交买入委托，可用资金只够一笔。
**特征画像**：冻结动作存在竞态窗口；需求未写并发规则；历史出现过超额冻结缺陷。
**方法选择**：场景法（主）—— 构造并发时序脚本（同时提交 / 先后毫秒级提交 / 一成功一失败重试）；错误推测法（辅）—— 重复提交、请求重放、超时重发。
**选择理由**：竞态窗口 + 无明确规则 + 历史缺陷，命中 F12/F14/F17。
**同类迁移**：撤单与成交竞态、库存扣减、缓存一致性、消息重放。

## 四、方法选择失败信号（触发质量闸门打回）

| 失败信号 | 说明 | 处置 |
|---------|------|------|
| 全部测试点都推荐"等价类 + 边界值" | 模型在做归一化偷懒，没有真正分类 | 打回第 2 步重做特征建模 |
| 组合爆炸却全量罗列 | 未识别组合规模，用例不可执行 | 强制估算组合数，> 20 必须降维 |
| 降维后不给损失说明 | 覆盖率不可信 | 必须补"舍弃了哪些组合 + 风险判断" |
| 状态机用判定表 | 判定表管不了"先后顺序" | 改状态迁移测试 |
| 选择理由是"常用方法""确保覆盖" | 依据是习惯不是特征 | 打回，要求引用特征信号 |
| 有约束关系却直接全组合 | 2^n 里混入不可能组合 | 先因果图标约束再化简 |
| 端到端流程只测基本流 | 异常流缺失 | 强制列出全部异常流 |

## 五、14 种方法速查（详细版见 method-catalog.md）

| 方法 | 一句话定位 | 不可替代的场景 |
|------|-----------|---------------|
| 等价类划分 | 输入域分域的骨架 | 任何带输入的功能，第一层必用 |
| 边界值分析 | 边界缺陷的收割机 | 范围/精度/极值类，性价比最高 |
| 判定表法 | 条件组合的完整性证明 | 条件 2~5、结果唯一 |
| 因果图法 | 条件约束的化简器 | 互斥/包含/唯一/要求约束 |
| 状态迁移测试 | 生命周期的覆盖器 | 状态 ≥ 3 的对象 |
| 场景法 | 业务走法的地图 | 端到端流程、异常流 |
| 正交试验设计 | 组合爆炸的降维器 | 主要效应 + 均匀分散 |
| 成对测试 Pairwise | 交互对的压缩器 | 两两交互为主的超大组合 |
| 分类树法 | 层级参数的组合器 | 树形结构的参数分解 |
| 错误推测法 | 历史缺陷的反向利用 | 幂等/并发/文案/降级盲区 |
| 语法测试 | 形式文法的正反例 | 报文/协议/格式校验 |
| 随机测试 | 超大域的统计覆盖 | 不可枚举输入域、稳定性 |
| 探索性测试 | 无规则区域的学习 | 需求缺失、新功能认知 |
| 规格说明/检查表法 | 需求条目的核对器 | 防止需求条目级遗漏 |
