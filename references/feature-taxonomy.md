# 特征形态分类学（完整版）

> 18 类特征形态，按 6 大类组织。每类给出：定义、判定信号、要问的问题、证券/通用示例、对应方法、产出物、常见漏测。
> 速查索引用 `index.json`；方法选择的固化映射用 `mapping-matrix.md`；本文件用于向人解释"为什么这类特征要用这个方法"。

分类目的不是穷尽，而是让判断**收敛**。特征一旦分类确定，方法就是推论。遇到分类学没有的形态，走 SKILL.md 的「扩展规则」，不要硬归类。

## 大类 A · 输入特征（被测对象是"输入数据"）

### A1 连续数值区间（F1）
- **定义**：单个输入在连续域上取值，独立决定结果，有明确上下界。
- **判定信号**：一个字段、一个范围、非通过即拒绝。
- **要问的问题**：有效域边界？无效域分几类？开区间还是闭区间？
- **证券示例**：委托价格 ∈ [0.01, 涨停价]；融资买入保证金比例范围；可申购数量上下限。
- **方法**：等价类划分（主）+ 边界值分析（辅）。
- **产出**：有效/无效等价类表 + 上点·离点·内点矩阵。
- **常见漏测**：只测中间值；把闭区间当成开区间测。

### A2 离散枚举/集合（F2）
- **定义**：输入为有限枚举值，不同枚举走不同分支，存在非法枚举。
- **判定信号**：下拉框、类型字段、状态码入参。
- **要问的问题**：枚举全集？每类是否触发独立规则？非法枚举如何拒绝？
- **证券示例**：委托方式（限价/本方最优/对手方最优/最优五档…）；账户类型（个人/机构/产品户）；证件类型。
- **方法**：等价类划分（主，按类别）+ 错误推测法（辅，补非法枚举）。
- **产出**：每个有效枚举 ≥ 1 条用例 + 非法枚举用例。
- **常见漏测**：枚举全集之外的值；大小写/全角变体。

### A3 精度/步长/格式（F3）
- **定义**：输入有最小变动单位、小数位、步长或格式约束。
- **判定信号**：价格两位小数、100 股整数倍、格式正则。
- **要问的问题**：步长？超精度如何舍入？格式字符集边界？
- **证券示例**：价格 0.01 元步长；数量 100 股整数倍（科创板 200 股起 1 股递增）；身份证号校验位。
- **方法**：边界值分析（主）+ 错误推测法（辅）。
- **产出**：步长边界矩阵 + 超精度/超长/非法字符用例。
- **常见漏测**：只测范围不测舍入；漏掉全角数字、前后空格、千分位。

### A4 动态阈值（F4）
- **定义**：阈值随基准值浮动，基准值本身有回退链，不同板块/产品规则有差异。
- **判定信号**："不超过基准的 X%"、实时限额、动态价格区间。
- **要问的问题**：基准值从哪来？基准缺失回退到哪？各板块差异点？
- **证券示例**：价格笼子（买入价 ≤ 买入基准价×102%，沪深主板/创业板另有 +0.1 元孰高兜底，科创板无，北交所 ±5%）；动态保证金率。
- **方法**：边界值分析（主，多组基准值构造动态边界）+ 等价类划分（辅，基准行情态分层）。
- **产出**：基准值 × 阈值矩阵（含回退链、板块差异行）。
- **常见漏测**：只测一组基准价；漏测回退链（无卖一时取买一、无盘口取最近成交、无成交取前收）。

### A5 语法/协议输入（F15）
- **定义**：输入须符合形式语法（报文、协议、文件模板）。
- **判定信号**：API 报文、FIX 协议、CSV 导入模板。
- **要问的问题**：语法规范？必输字段？非法报文如何拒绝？
- **证券示例**：柜台接口报文；行情订阅报文；批量委托文件导入。
- **方法**：语法测试（主）+ 等价类划分（辅，字段取值域）。
- **产出**：语法正例集 + 每条文法规则的违反用例。
- **常见漏测**：只测合法报文，不测畸形/截断/超长报文。

### A6 随机/超大输入域（F16）
- **定义**：输入域极大不可枚举，需要统计性覆盖。
- **判定信号**：模糊搜索、压力数据、fuzz。
- **要问的问题**：输入分布？边界区域？样本量与种子？
- **证券示例**：行情回放压测；模糊搜索证券名称；风控规则 fuzz。
- **方法**：随机测试（主）+ 等价类划分（辅，先分层再抽样）。
- **产出**：分层抽样方案 + 固定种子 + 失败样本归档。
- **常见漏测**：不设随机种子，失败无法复现。

## 大类 B · 逻辑特征（被测对象是"规则与分支"）

### B1 布尔条件组合（F5）
- **定义**：多个条件共同决定一个结果，条件数 2~5，结果唯一。
- **判定信号**："同时满足""任一满足"、多重开关。
- **要问的问题**：条件数？2^n 组合是否都合法？哪些组合触发不同动作？
- **证券示例**：风控多重开关；资金+持仓+权限联合校验；可撤单判定（状态×时段×板块×是否成交）。
- **方法**：判定表法（主）+ 因果图法（辅，有约束时）。
- **产出**：条件桩/动作桩全组合表 + 化简记录。
- **常见漏测**：只测各条件单独为真，漏组合。

### B2 条件间强约束（F6）
- **定义**：条件间存在互斥（E）、包含（I）、唯一（O）、要求（R）、屏蔽（M）关系，部分组合逻辑上不可能。
- **判定信号**："A 与 B 不能同时""选了 A 必须选 B"。
- **要问的问题**：哪些条件互斥？哪些必然同发？非法组合如何拒绝？
- **证券示例**：计费折扣叠加（会员折扣与满减互斥）；市价委托与价格字段的约束；证件类型与国籍联动。
- **方法**：因果图法（主，标约束并化简）+ 判定表法（辅，承接化简结果）。
- **产出**：因果图（含约束标注）+ 化简后判定表。
- **常见漏测**：判定表里混入不可能组合，浪费用例还掩盖真问题。

### B3 分段/阶梯规则（F7）
- **定义**：同一输入按区间分段适用不同规则，段间有临界点。
- **判定信号**：费率表、阶梯、分档。
- **要问的问题**：分几段？临界点归属？跨段输入如何计算？
- **证券示例**：佣金费率分档；经手费阶梯；风险等级 C1~C5 分档。
- **方法**：等价类划分（主，每段一类）+ 边界值分析（辅，每个临界点两侧）。
- **产出**：段等价类表 + 临界点归属用例。
- **常见漏测**：临界点该进上段还是下段搞错。

### B4 优先级/仲裁（F8）
- **定义**：多候选竞争同一资源，有优先级规则，平级需仲裁。
- **判定信号**："价格优先、时间优先"、路由顺序、降级顺序。
- **要问的问题**：优先级维度？同优先级如何仲裁？是否依赖时序？
- **证券示例**：撮合规则（价格优先→时间优先）；订单路由；限流降级顺序。
- **方法**：判定表法（主，优先级维度组合）+ 场景法（辅，竞争时序）。
- **产出**：优先级判定表 + 竞争场景脚本。
- **常见漏测**：只测最高优先级胜出，漏同优先级仲裁。

## 大类 C · 组合特征（被测对象是"参数空间"）

### C1 参数组合爆炸（F9）
- **定义**：多参数各自多取值，笛卡尔积 > 20，参数间交互弱。
- **判定信号**：配置矩阵、兼容性矩阵、多筛选条件。
- **要问的问题**：组合总数？关键交互对？能接受的覆盖率损失？
- **证券示例**：委托类型(6)×板块(4)×时段(3)=72；APP 机型×OS×网络矩阵；报表筛选条件组合。
- **方法**：正交试验设计（主，主要效应）+ 成对测试 Pairwise（辅，两两交互）。层级结构参数可用分类树法。
- **产出**：正交表实例化 / Pairwise 用例集 + 参数对覆盖率 + **损失说明**。
- **常见漏测**：不估算规模就随手抽样；降维后不给损失说明。

## 大类 D · 行为特征（被测对象是"状态与流程"）

### D1 状态迁移（F10）
- **定义**：对象有生命周期，同一操作在不同状态结果不同，状态数 ≥ 3。
- **判定信号**：状态字段、流转图、"已 X 之后不能 Y"。
- **要问的问题**：状态集？事件集？非法迁移？不可达状态？
- **证券示例**：委托单状态（待报→已报→部成→已成/已撤/废单）；账户状态（正常/冻结/休眠/销户）。
- **方法**：状态迁移测试（主）+ 场景法（辅）。
- **产出**：状态-事件矩阵 + 全合法迁移 + 非法迁移 ≥ 3 条。
- **常见漏测**：只测合法流转，不测非法迁移防护（绕过前端直接构造报文）。

### D2 流程场景（F11）
- **定义**：跨模块端到端链路，存在多种走法与中断恢复。
- **判定信号**：流程图、多个系统、"先…再…然后…"。
- **要问的问题**：基本流？备选流？异常中断如何恢复？
- **证券示例**：开户→测评→转账→委托→成交→清算→对账；理赔流程。
- **方法**：场景法（主）+ 错误推测法（辅）。
- **产出**：基本流/备选流/异常流场景清单。
- **常见漏测**：只覆盖基本流，异常流靠临场发挥。

### D3 时序与并发（F12）
- **定义**：存在竞态窗口、乱序到达、超时/重试/重放。
- **判定信号**："同时""先后""超时后重发"。
- **要问的问题**：竞态窗口？时序错误时系统承诺什么？重试是否幂等？
- **证券示例**：并发下单超额冻结；撤单与成交竞态；超时重连后状态一致性。
- **方法**：场景法（主，时序脚本）+ 错误推测法（辅，乱序/重放极端情形）。
- **产出**：时序图/竞态场景 + 高频压测建议。
- **常见漏测**：默认串行世界，不测乱序到达。

### D4 跨功能端到端（F18）
- **定义**：跨多系统的闭环，需校验数据一致性。
- **判定信号**：对账、清算、跨系统流转。
- **要问的问题**：链路几个系统？一致性校验点？断链如何发现？
- **证券示例**：委托-成交-清算-对账闭环；支付-入账-对账。
- **方法**：场景法（主）+ 状态迁移测试（辅，跨系统状态对齐）。
- **产出**：端到端场景 + 一致性校验点清单。
- **常见漏测**：各模块各自测完就收工，不测链路。

## 大类 E · 计算特征（被测对象是"计算结果"）

### E1 数值计算（F13）
- **定义**：输出由公式计算，涉及金额/费率/比率，有舍入与精度规则。
- **判定信号**：公式、分档、最低收费、四舍五入。
- **要问的问题**：公式与精度？舍入还是进位？尾差？基准值来源？0 与极值？
- **证券示例**：佣金 = max(5 元, 成交额×费率)；冻结金额 = 价×量+费用；涨跌停价 = 前收×(1±比例) 四舍五入到分。
- **方法**：边界值分析（主，舍入分界点与极值）+ 等价类划分（辅，输入分档）。
- **产出**：计算校验矩阵（尾差、进位、0 值、负数、极值）。
- **常见漏测**：不测舍入分界点（乘积第 3 位为 5 这类）。

### E2 数据依赖/幂等（F14）
- **定义**：结果依赖历史数据或缓存状态，同一请求可能重复提交。
- **判定信号**：幂等键、缓存、重放、断点续传。
- **要问的问题**：幂等键？重复请求返回什么？缓存失效策略？
- **证券示例**：重复提交委托；柜台消息重放；持仓缓存脏读。
- **方法**：错误推测法（主，反向用例）+ 场景法（辅，触发流程）。
- **产出**：幂等/重放/一致性反向用例清单。
- **常见漏测**：不测重复提交，默认请求只来一次。

## 大类 F · 经验特征（被测对象是"规则之外的盲区"）

### F1 无规则经验型（F17）
- **定义**：需求未明确约束，但历史缺陷高发或属"以为不会出问题"的区域。
- **判定信号**：需求文档没写、靠惯例、历史缺陷聚集。
- **要问的问题**：历史缺陷库同类功能出过什么？同类系统在这摔过什么？
- **证券示例**：异常提示文案；降级行为；极端行情下的排队表现。
- **方法**：错误推测法（主）+ 探索性测试（辅）。
- **产出**：缺陷清单→反向用例 + 探索性测试 charter。
- **常见漏测**：因为没有规则文档就完全不测。
