# 质量闸门（9 道）

> 大模型的输出天然"看起来合理"。以下 9 项是可以机械检查的。
> 第 ① ⑤ ⑥ ⑦ ⑧ ⑨ 项由 `scripts/validate-output.py` 自动检查；② ③ ④ 需要人复核（脚本给出线索）。

---

## ① 可追溯性
每条测试点都能回溯到需求原文片段（`原文依据` 字段非空）。出现无原文依据的内容，一律进 `[待确认]` 清单，不得直接进用例。
- **脚本检查**：`原文依据` 为空的条目计数。

## ② 无编造
模型不得自行补充业务规则。典型信号：它主动写出了需求文档里没提到的比例、阈值、时限、枚举值。
- **人工复核**：抽查所有数字型规则，逐条对照原文依据；脚本无法自动判定，但会把所有含数字的 `业务规则` 字段列出来供抽查。

## ③ 特征类型完备
18 类特征中本次需求至少应命中 3 类以上；若全部落在"连续数值区间/离散枚举"，说明模型在做归一化偷懒，必须打回重做特征建模。
- **脚本检查**：统计特征类型分布，单一类型占比 > 70% 告警。

## ④ 方法匹配合理
抽查 5 条"选择理由"，看依据是特征还是习惯。出现"常用方法""确保覆盖""比较保险"这类空话即视为不合格。
- **脚本检查**：扫描空话模式（`常用|通常|确保覆盖|比较保险|一般来说`）。

## ⑤ 降维有损失说明
凡标注"需降维"的测试点，必须给出：组合总数、降维后数量、覆盖率、被舍弃的组合清单及风险判断。
- **脚本检查**：`组合规模 > 20` 但 `需降维=false` 或 `降维目标` 为空的条目。

## ⑥ 边界完整性
检查是否同时存在上点、内点、离点三层；是否覆盖 0、负数、超精度、超长、溢出等极值输入。
- **脚本检查**：用例集中"边界"类型用例计数为 0 的测试点。

## ⑦ 无效域占比 ≥ 30%
无效等价类 + 离点 + 异常流的用例占比不低于 30%。低于这个比例，说明用例集只覆盖了正常路径。
- **脚本检查**：`用例类型 ∈ {无效, 边界·离点, 异常}` 的占比，阈值默认 30%（可调）。

## ⑧ 预期结果可判定
全局搜索"应该正常""提示错误""符合预期""正确处理"这类表述，出现即打回。预期结果必须包含具体文案、状态或数值。
- **脚本检查**：禁词模式（`应该正常|提示错误|符合预期|正确处理|正常返回|成功处理`）。

## ⑨ 图片证据闭环
需求素材里的图是正式需求源，必须闭环：**正文每处引用图的措辞 → 必须锚定到具体图号 → 必须提取出八类元素 → 必须落进至少一条需求点**。断在任一环即不合格。
- **检查项**：
  1. 正文出现 `如图所示 / 如下图 / 见下图 / 如左图所示 / 如图 1 所示 / 图 3-1 所示 / 按下图 / 如下截图 / 如上图 / 如下表 / 见附表 / 界面如下 / 参考下图 / 参照下列图` 等措辞的段落，其对应需求点的 `图片依据` 不得为 `[]`；
     （脚本已覆盖上述写法，并用负向断言排除「例如图片」「地图」「图表」这类误报；新增写法时同步更新 `validate-output.py` 的 `IMAGE_REF_PHRASE`）
  2. `图片依据[].图号` 必须形如 `img-N` 且存在于 `manifest.json` 的 `images[]`；
  3. `图片依据[].提取元素` 条数 ≥ 2，且不得出现「若干」「一些」「等」这类概述词；
  4. `manifest.json` 中未被标记「排除」的图，至少被一条需求点引用（否则进 `gaps[]`，标注「有图无引用」人工复核）；
  5. `gaps[]` 含 `硬缺口` / `提取失败` 时，最终报告必须声明证据强度已降级。
- **脚本检查**：读入 `asset-inventory.json`（可选 `--inventory`）与 `manifest.json`（`--manifest`），
  对 `文本依据` 命中引用措辞但 `图片依据` 为空的条目 → **硬性不通过**；
  `图片依据` 存在但 `图号` 不合法 / `提取元素` < 2 条 → **硬性不通过**；
  缺 `图片依据` 字段（老格式产物）但有引用措辞 → 告警，提示这是未升级产物。

---

## 通过标准

| 级别 | 条件 |
|------|------|
| 通过 | ①⑤⑥⑦⑧⑨ 全部通过，②③④ 人工复核无疑义 |
| 有条件通过 | 脚本告警 ≤ 3 条且均为可解释的业务原因，告警原因写入交付说明 |
| 打回 | 任一硬性闸门（①⑤⑦⑧⑨）不过，或出现"全部推荐等价类+边界值" |

## 数值校准

- 无效域占比阈值 30% 是经验值：纯校验类功能可到 50%，纯展示类可降到 20%。
- 按团队的线上缺陷分布校准：若线上事故 40% 来自边界，就把闸门 ⑥ 升为硬性门禁。
- 闸门 ⑨ 在**素材含图**时才是硬性门禁；纯文字素材下自动跳过（脚本会说明"未提供素材清单，跳过闸门⑨"）。
